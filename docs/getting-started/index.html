Getting started

Quadrilingo keeps Confluence pages in English, French, German and Italian, linked to each other. This page takes you from installation to your first translated page.

What you need

  • A Confluence Cloud site. (Data Center and Server are not supported.)
  • To install: a site admin (or anyone your admins allow to install apps).
  • To turn translation on for a space: space admin rights on that space.
  • To translate a page: permission to add pages in that space.

You do not need a DeepL, Google, OpenAI or any other translation account, and you never enter an API key. Translation is included in your subscription.

Step 1 — Install the app

  1. In Confluence, open Apps → Explore more apps (or go to the Atlassian Marketplace).
  2. Search for Quadrilingo and select Try it free.
  3. Review the access the app requests, then confirm.

What the app asks to access, and why:

AccessWhy
Read pagesTo read the page you want to translate.
Write pagesTo create and update the translated pages.
Read content summariesTo notice when a source page is edited, so translations can be marked Outdated.
Read space detailsTo check what you may do in a space (turn translation on, add pages) and to list your spaces on the Get started page.
App storageTo keep space settings, glossary and links between pages.
Connection to api.deepl.comTo send page text to our translation provider. Code blocks, macro settings, link addresses, mentions, e-mail addresses and phone numbers are not sent.

Step 2 — Translate your first page

  1. Open any page in a space where you can add pages.
  2. Select ••• (More actions) → Translate this page. The menu item is in English for now, whatever your Confluence language; the dialog itself follows your language.
  3. The first time you use the app, Atlassian asks you to Allow access for it (once per person). This is normal: the app checks with your own permissions that you may read the page, add pages and edit existing translations. The translated pages are then written by the app.
  4. If translation is not on for this space yet, the dialog offers Turn on for this space. Select it (space admins only; other people see who to ask). The original language is pre-selected from the text of the page you are on; you can change it later in the space settings, as long as no page of the space is translated yet.
  5. Check the languages:
    • Original language: the language the pages of this space are written in. It is shown at the top of the dialog.
    • Translate into: the other languages among English, French, German and Italian are already ticked. Untick any you don't need.
  6. Select Translate.

Shortcut: translate a sample page

The app's Get started page offers Translate a sample page. It creates a short sample page in your name in the chosen space, turns translation on there if needed (space admins only), and translates it. You can delete the sample page afterwards.

Step 3 — Open the translation

  • Translations are created in the background. A short page takes a few seconds; a long page can take a few minutes. You can leave the page meanwhile.
  • When it is done, the dialog shows Open next to each language, and a language label appears under the page title, for example EN · FR · DE · IT. Select the label to see every version with its status, then Open the one you want. See Language switcher.
  • Each translation is a normal Confluence page, placed under the original page in the page tree, with a translated title.
