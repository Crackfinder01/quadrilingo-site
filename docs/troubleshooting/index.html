Troubleshooting

Status words in bold and the messages quoted below are taken from the English interface.

What you seeLikely causeWhat to do
“Translate this page” is not in the ••• menuThe app is not installed on this site, or you are on a blog post / whiteboard / database rather than a page, or the page is still a draft.Ask a site admin to check Apps → Manage apps. Publish the page first.
“Translation is not turned on for this space”No space admin has enabled translation for this space.A space admin can turn it on from the dialog or in Space settings.
“Only space admins can change these settings”You are not a space admin.Ask a space admin (listed in Space settings → Permissions).
Atlassian asks you to “Allow access”First use: the app checks your own permissions (read the page, add pages, edit existing translations) before translating, so Atlassian asks for your consent once per person.Allow it. Without consent, the app can't check your permissions and won't translate.
“You can't add pages in this space”Translations are created with your permissions.Ask a space admin for “Add pages” permission, or ask a colleague who has it.
The translation takes a long timeTranslations run in the background; long pages and several languages take longer. Many translations at once on the site are queued.Wait a few minutes and reopen the dialog. After 15 minutes without progress, the language shows Delayed: tick it and select Translate again. If it happens again, contact support.
A language shows “Error”The app could not write the page: missing permission, page restrictions, or your organisation's app access rules (data security policies) block the app in this space.Check restrictions on the original page and the space. An org admin can check app access rules in Atlassian Administration. Then update the translation again.
“Quadrilingo does not have “Can edit” on this page…”, and no language label or menu on the originalThe original is restricted for editing and Quadrilingo does not have Can edit on it (Share → Specific access). Quadrilingo translates it without ever editing it or changing its restrictions. The translation gets the same edit rights (plus Quadrilingo). The language switcher shows on the translations, not on the original.Nothing to do: translate as usual. To get the language switcher on the original too, open Share on the original, add Quadrilingo under Specific access with Can edit (or ask an admin).
“Confluence refused an operation by Quadrilingo on this page.”Confluence rejected one of the app's requests on this page or its translation.Start the translation again from the original. If the error comes back, contact support.
A paragraph is still in the original languageThe app kept the original paragraph because the translation would have broken its formatting (link, mention, code).Edit the translated page by hand, or update the translation later. If it happens often on the same kind of content, tell support.
The title ends with “(DE)”, “(FR)”…A page with the translated title already exists in the space.Rename one of the pages if you want. The link between pages is not affected.
“Outdated” doesn't appear after I edited the originalConfluence notifies the app up to about 3 minutes after publishing. Adding or removing a comment does not count as a change. Edits are not tracked without an active subscription, or while translation is turned off for the space. A translation edited by hand shows Edited by hand instead.Wait 3 minutes and reload. Check that the page you edited is the original, not a translation. Check that the subscription is active and translation is on for the space. The Translate this page dialog on the original always shows the real status.
A translation shows “Up to date” although the original changedThe edit was made while translation was turned off for the space, or without an active subscription. Such edits are seen the next time the original is edited.Open Translate this page on the original: it compares with the current text and shows the real status. Update from there.
A translation is “Up to date” again after I restored an old version of the originalExpected: the restored text is the one this translation was made from.Nothing to do. Languages that differ from the restored text stay Outdated.
Automatic updates don't run“Update translations automatically” is off for the space; the update is still in its 10-minute wait; the translation was Edited by hand (never overwritten automatically); the language has no translation yet (automatic updates never create pages); the monthly allowance is used up (Volume used up); the subscription is inactive; or the option was turned on after the page became outdated (it is then updated at the next edit of the original).Check Space settings and Quotas and plans. To update now, use ••• → Translate this page on the original.
“This month's translation volume is used up”The site used its allowance for this calendar month.Existing translations stay readable. You can translate again from the 1st of next month (UTC), or after asking us for a higher allowance. Nothing restarts on its own: start the translation again from ••• → Translate this page. See Quotas and plans.
“Not enough volume left this month”This translation could need more characters than are left this month.Untick some languages under Translate into, or wait until the 1st of next month (UTC).
The dialog warns that the page seems to be written in another languageThe page does not look like it is written in the space's original language. It would be translated as if it were, which can give a poor result.Check the original language in Space settings. A space has one original language; it can no longer change once pages are translated.
A translation shows “Edited by hand” and is not updatedSomeone edited the translated page directly. The app never overwrites it automatically, and the dialog leaves it unticked.To replace it: on the original, open Translate this page, tick that language, tick “Also replace translations that were edited by hand”, then Translate. Copy any manual change you want to keep first. Consider adding the term to the Glossary.
A language shows “Not available” in the language menuA version exists but you cannot open it: page restrictions, or the page was trashed or deleted.Ask the page owner for access. If the page was deleted, update that language from the original.
The language list doesn't show on my phoneThe Confluence mobile apps may not display the app's language list.Open translations from the page tree (they are child pages of the original) or from search.
I moved a translation and it is no longer updatedA translation must stay under its original page.Move it back under the original page (the dialog says so).
I restored a translation from the trash and the language now has two pages, or the menu says “This page is not linked to other languages.”Once the app has seen a translation as gone, it stops linking to it; the next translation into that language creates a new page. A page restored from the trash afterwards is not linked again.Delete the extra page. If no new page was created yet, translate that language again from the original: a new linked page is created and the restored page stays unlinked. A page restored before any translation or update ran is not affected.
I copied a page and the language menu says “This page is not linked to other languages.”The copy carried the link information of the page it was copied from, but the app only trusts links that match in both directions.The copy is not linked to the original's translations. If you need the copy in other languages, contact support.
I changed the glossary but existing translations did not changeExpected: a glossary change applies to the next translations and updates only. Nothing is re-translated automatically.Update the pages that matter from ••• → Translate this page, or let them pick up the glossary at their next change. See Glossary.
I can't see the glossaryOnly space admins can see and change it.Ask a space admin.
The glossary screen shows “short acronym”A required translation contains a short acronym (such as AI → IV). It will be replaced wherever it appears, whatever it means.Keep the row only if the acronym has a single meaning in this space's pages. The warning does not block saving.
“The space glossary could not be applied to this translation.”The translation service could not use the glossary for this translation, which was made without it.Run the translation again later from Translate this page.
Watchers get notifications for every updateUpdating a translated page is a normal page edit in Confluence.Turn off automatic updates for busy spaces, or ask watchers to unwatch translations.

Contacting support

Write to support@quadrilingo.com in English, French or German. To help us, include:

  • your site URL (https://yourcompany.atlassian.net);
  • the page ID or link, the languages involved, and the approximate time;
  • what you expected and what you saw (a screenshot helps).

You don't need to send us the page content. We never ask for your Atlassian password or an API token.
