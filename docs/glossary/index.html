Glossary

Machine translation sometimes translates words that should never change (your product name) or picks a different word than the one your company uses. The glossary fixes this, per space: it applies to every page of the space. Labels in bold are the ones on the screen (English version; the screen follows your Confluence language).

Where to find it

Space settings → Quadrilingo, below the translation settings: section Space glossary.

Only space admins can see and change the glossary. The app checks this on every load and every save.

Two lists

ListExampleEffect
Do not translateAcme Cloud, SAP, KST-4100Names of products, companies or people, kept as they are in every language.
Required translationsFR demande de congé · DE Ferienantrag · IT richiesta di ferie · EN holiday requestOne term per language, on the same row. Whenever one of these terms is translated into another language of the row, that language's term is used.

For Required translations, columns are French, German, Italian, English and Swiss Standard German:

  • Fill in at least two languages per row. Leave a language empty when it has no required term.
  • The Swiss Standard German column is used only when the space translates into Swiss Standard German (see Space settings). When it is empty, the German term is used. Example: German Urlaub, Swiss Standard German Ferien.
  • In German pages, terms of both German columns are recognised.

Exact case: tick “Match upper and lower case exactly” when case matters (keep SAP, but not “sap”). A required-translation row written only in capitals (acronyms such as AHV/AVS) is always treated as exact case.

Add, edit or delete a term

  1. Open the glossary.
  2. Select Add a name (Do not translate) or Add a translation (Required translations).
  3. Type the term, or the term in each language, then select Apply.
  4. Select Save glossary. Until then, the screen shows Unsaved changes.

Use Edit or Delete on a row to change it.

Rules checked before saving:

  • Up to 500 names not to translate and 1,000 required translations, 100 characters per term.
  • Line breaks, tabs and the signs < > are not allowed.
  • The same term cannot appear twice in a list, and a term cannot be in both lists.

Short acronym warning. For a short acronym in a required translation (for example AI → IV, the Swiss disability insurance), the screen warns you: the acronym will be replaced wherever it appears, whatever it means, so “AI” meaning artificial intelligence would also become “IV”. Keep such a row only if the acronym has a single meaning in the pages of this space. The warning does not block saving.

If someone else saved the glossary after you opened the screen, saving is refused: reload the glossary, then make your changes again.

Import or export (CSV)

Under Import or export (CSV):

  • Show CSV displays the whole glossary as CSV text to copy (into a spreadsheet, for example).
  • To import, paste a CSV table into the text box and select Replace the glossary with this CSV. The import replaces the whole glossary shown; check it, then select Save glossary.

Format: header kind,term,fr,de,it,en,de-CH,case_sensitive, separated by commas, semicolons or tabs.

  • kind = dnt for a name not to translate (term in the term column), forced for a required translation (terms in the language columns).
  • case_sensitive = yes or no.

Example:

kind;term;fr;de;it;en;de-CH;case_sensitive
dnt;Acme Cloud;;;;;;yes
forced;;service de piquet;Bereitschaftsdienst;servizio di picchetto;on-call duty;Pikett;no

Import errors give the CSV line number. There is no file upload: copy and paste the text. Cells starting with =, +, - or @ are exported with a leading ' so that spreadsheets do not run them as formulas; the import removes it.

When the glossary applies

  • To the next translations and updates made after you save it.
  • Nothing is re-translated automatically after a glossary change, and no page is marked Outdated. To apply a change to an existing translation, update it from ••• → Translate this page on the original page, or wait for the next change of that page.
  • Volume: after a glossary change, the next translation or update of a page counts the whole page, but only in the languages the change affects. Example: changing a French/German term does not make Italian → English updates count again.
  • After each translation, the app checks that the names under Do not translate are still there. If one seems to have been translated, the dialog shows “To review: a protected glossary name may have been translated.”
  • If the glossary could not be applied to a translation, the dialog says so (“The space glossary could not be applied to this translation.”). Run the translation again later to apply it.
  • If the saved glossary cannot be read, nothing is translated in the space and the dialog asks a space admin to save the glossary again.

Tips

  • Start small: product names, team names, internal acronyms, and the 10–20 terms people complain about.
  • Swiss vocabulary (Pikett, Traktandum, Ferien) belongs in the Swiss Standard German column of a required translation.
  • Language names: if a page lists “Français / Deutsch”, add them under Do not translate.

Where the glossary is stored

In the app's Atlassian-hosted storage (Forge), for as long as the app is installed.

So that DeepL can apply it, a copy of the space glossary is also stored in our DeepL account (two copies when the space uses Swiss Standard German terms that differ from the German ones). Copies are replaced regularly and deleted automatically, at the latest 31 days after they were created. See our privacy policy and data flow description.
