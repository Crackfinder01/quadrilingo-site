Translate a page

How

  1. Open the page.
  2. Select ••• (More actions) → Translate this page (the menu item is in English for now; the dialog follows your Confluence language).
  3. Check the Original language shown at the top and the languages ticked under Translate into, then select Translate.

The translation runs in the background. You can close the dialog and keep working. When it is done, the dialog shows Open next to each language, and a language label appears under the page title (see Language switcher).

In the dialog, each language shows its status: Not translated, Up to date, Outdated, In progress, Delayed, Edited by hand, Volume used up, Error, Status unknown or Page not found. Languages that need work are ticked when the dialog opens; up-to-date languages and languages edited by hand are not.

Who can do it: anyone who can add pages in the space, once translation is on for the space. Updating an existing translation also needs permission to edit that translated page. The app checks these permissions as you before anything is sent for translation; the translated pages are then written by the app.

Where the translation goes

  • Each translation is a child page of the original, with a translated title.
  • If a page with that title already exists in the space, the language code is added: for example Onboarding (DE).
  • The original and its translations are linked: the app knows which page is the German version of which, and from which version of the original it was made.
  • Translations are normal pages: they appear in search, in the page tree, in PDF/Word exports, and on the Confluence mobile apps.
  • Permissions: a page restricted for viewing also restricts the pages under it in Confluence, so translations of a restricted page are not visible to people who cannot see the original.
  • Original page restricted for editing: Quadrilingo translates it without ever editing it or changing its restrictions. The translation gets the same edit rights (plus Quadrilingo). The language switcher shows on the translations, not on the original. The dialog says so when Quadrilingo does not have Can edit on the page (Share → Specific access).

What is translated, what is not

TranslatedKept as is (never sent for translation)
Page titleCode blocks and inline code
Paragraphs, headings, listsMacro settings (Jira filters, table of contents, anchors…)
Table cells and table headersMentioned people (@name)
Panels (info, note, warning…), quotesEmojis, dates
Tasks and decisionsLink addresses (the visible link text is translated, unless it is the address itself)
Expand titles, captionsE-mail addresses, phone numbers, web addresses
Status labels (e.g. “IN PROGRESS”)Cells that contain only an amount (e.g. CHF 450.–) or only numbers
Image alt textImages and attachments
Text inside “rich text” macros such as Excerpt or Page PropertiesPage comments and inline comments

Inline comments of the original are not copied to the translation.

Numbers and amounts are checked after translation: if a number may differ from the original, the dialog shows “To review: a number, amount or currency may differ from the original page.” Names listed under Do not translate in the space Glossary are checked the same way.

If a paragraph stays in the original language

The app protects your layout. If a paragraph comes back from translation with broken formatting (a lost link or mention, for example), the app first retries, then accepts the text with simplified formatting (bold, italic…), and only if that fails, keeps the original paragraph rather than damage the page. You may then see a paragraph in the source language inside a translated page; the dialog then says “Some passages could not be translated and were left in the original language.” Fix it by hand, or update the translation later.

Editing a translated page

You can edit a translation like any page, for example to improve a sentence. The app notices it: the translation shows Edited by hand and is never overwritten automatically. It is replaced only if you tick that language in the dialog on the original page and tick “Also replace translations that were edited by hand”. See Outdated translations.

Supported content

  • Pages: yes. Blog posts: no (the dialog says only pages can be translated).
  • Languages: English, French, German, Italian, in any direction.
  • Very long pages: supported; they take longer (several minutes for very long pages).

How much allowance it uses

Each translation uses characters of the source text (spaces included), counted once per target language. Translating a 5,000-character page into 3 languages uses about 15,000 characters. Code, macro settings, mentions and number-only cells are not counted. When you update a translation, passages already translated are reused and not counted again, except right after a glossary change (see Glossary). See Quotas and plans.
