Outdated translations

The main reason to use Quadrilingo instead of copying translations by hand: when the original page changes, you see which translations are behind, and you bring them up to date from the page menu or automatically. Labels in bold are the ones on the screen (English version; the screens follow your Confluence language).

How a translation becomes “Outdated”

  1. Someone edits and publishes the original page.
  2. A few minutes later (Confluence notifies the app with a delay of up to about 3 minutes), each translation of that page is marked Outdated.
  3. You see it everywhere the app shows a status: in the label under the page title, in the language menu that opens from it (see Language switcher), and in the Translate this page dialog.

What does not make a translation outdated:

  • Adding, answering or removing a comment on the original (page or inline comment). Only a change of the page content counts.
  • Editing a translation. It does not mark the original or the other translations as outdated (see “Edited by hand” below).
  • Changing the space glossary. It applies to the next translations and updates only (see Glossary).

Restoring an older version of the original: if you restore the exact text a translation was made from, that translation becomes Up to date again. Only the languages that really differ from the restored text stay Outdated.

An active subscription is needed. Without an active subscription or trial, edits are not tracked: nothing is marked Outdated, so a label can still say Up to date after the original changed. Once the subscription is active again, a page is checked the next time its original is edited.

Update an outdated translation yourself

  1. Open the original page.
  2. Select ••• (More actions) → Translate this page.
  3. Outdated languages are already ticked under Translate into. Up-to-date languages and languages Edited by hand are left unticked.
  4. Select Translate.

If you open the dialog on a translated page, it tells you that the page is a translation and offers Open the original page: updates always start from the original.

Passages that did not change since the last translation are reused and are not counted again in your monthly volume. The dialog shows the maximum volume an update may use; it is often less. Exception: right after a glossary change, the next update counts the whole page for the languages the change affects.

Automatic updates (optional, per space)

A space admin can turn on “Update translations automatically” in the space settings. Then:

  • About 10 minutes after the original changes, its outdated translations are updated without anyone clicking. Several edits made during those 10 minutes are combined into one update per language, made from the latest version.
  • Only existing translations are updated. No new translation page is ever created automatically: to add a language, translate the page yourself.
  • A translation Edited by hand is never overwritten automatically.
  • Automatic updates use your monthly translation volume, like manual ones. On a busy space, consider leaving the option off and updating pages once they are stable. See Quotas and plans.
  • If the monthly volume is used up, the update does not start and the language shows Volume used up in the dialog. Nothing restarts on its own: the language is updated at the next edit of the original once volume is available again, or when you update it from the dialog.
  • If the option is turned off, the language is removed from Translate into, or translation is turned off for the space during those 10 minutes, the planned update does not happen and uses nothing.
  • While an automatic update is waiting, the translation still shows Outdated. You can update it yourself at any time; the automatic update then has nothing left to do.

Turning the option on does not update, on the spot, pages that are already outdated. Each of them is updated the next time its original is edited. To catch up right away, update them from the dialog.

Edited by hand

You can edit a translated page like any page, for example to improve a sentence. The app notices it: the translation shows Edited by hand and is never overwritten automatically, even if the original changes later.

To replace it anyway with a fresh translation:

  1. On the original page, open Translate this page.
  2. Tick the language marked Edited by hand. The option “Also replace translations that were edited by hand” appears.
  3. Tick it and select Translate. The changes made directly on that translated page are lost, so copy anything you want to keep first.

A translation edited by hand keeps the Edited by hand status when the original changes later; the dialog on the original is where you decide to replace it.

Tip: if you often correct the same word, add it to the Glossary instead.

Translation turned off in a space

While translation is turned off for a space, edits of its original pages are not tracked. After it is turned on again, a page is checked the next time its original is edited (any edit, adding a comment included). Until then, its translations can still show Up to date. The Translate this page dialog always compares with the current text of the page, so it shows the real status.

When updates stop

  • Monthly volume used up: see above and Quotas and plans.
  • No active subscription: translating and updating are blocked; reading keeps working.
  • The app cannot write the translated page (page restrictions, approval required in the space, your organisation's app access rules): the language shows Error in the dialog with the reason. See Troubleshooting.

Notifications

People watching a translated page may receive a Confluence notification when it is updated.
